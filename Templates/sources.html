HTML and CSS templating

How do we use templates?

For our website, we wanted to provide both good content and a compelling design. In order to do both of these things in time, we chose to implement a css and html template in order to speed up the early development stages. We chose to use a template from HTML5 UP because of the quality of their templates and the fact that they are highly customizable. Because of the customizability of the templates, we were able to take the basic design, but modify it in our own ways on our different pages. For example, we changed the color scheme of the template to match our own color scheme, and we also changed the layout of the pages to better fit our content.

What exactly does our template provide?

The template we chose is called "Escape Velocity". It includes an adaptable base layout and a CSS file that formats different HTML tags, allowing us to apply formatting in very customizable ways. For example, when designing this page, we used the "highlight," "style1," and "style3" classes to format the text and background in a unique way not present in the initial template. In this way, the template we downloaded is not a crutch, but rather a foundation for us to build upon.

How does the template use JavaScript?

If you look into the "Escape Velocity" template example website, you might notice that the template also includes JavaScript. The included JavaScript is used in order to change formatting and margins based on the size of the screen, as well as setting up some basic listeners and primitive UI. It does not contribute in any way to the progression system of our website or to any of the other rubric requirements of the TSA Webmaster challenge.

AI and External Sources

Our Views on AI and External Sources

This website was created for two reasons. The first was to compete in a less popular category of the TSA competitions, and the second was to learn more about web development and programming. We wanted our work to be our own, and decided to use as little AI and external sources as possible in order to learn as much as possible. This project has truly been a learning experience, and in hindsight, this was one of the best decisions we could have made. Both of us have learned so much along our journey, and the extra hours were certainly worth the knowledge and experience we gained.
